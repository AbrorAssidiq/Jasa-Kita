# Jasa Kita - Guest Frontend Starter
Halaman frontend untuk aktor Guest/pengunjung tanpa akun.

- access.html: akses tanpa akun
- home.html: beranda Guest
- profile.html: profil Guest
- categories.html: daftar kategori
- search.html: pencarian/filter sederhana
- providers.html: daftar penyedia contoh
- provider-detail.html: detail penyedia contoh
- login-required.html: pemberitahuan login sebelum memesan

Buka `access.html` menggunakan VS Code Live Server. Konten penyedia masih data contoh, belum terhubung database.
