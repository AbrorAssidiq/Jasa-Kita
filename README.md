# Jasa Kita

**Platform Aplikasi Layanan Jasa**

Jasa Kita merupakan proyek perancangan aplikasi berbasis digital yang bertujuan untuk mempermudah pengguna dalam mencari dan menggunakan berbagai layanan jasa.

Proyek ini dikembangkan dengan memperhatikan kebutuhan pengguna, kemudahan navigasi, serta pengalaman penggunaan aplikasi melalui perancangan UI/UX.

## Project Status

🚧 **In Progress – UI/UX Design**

Saat ini proyek berada pada tahap perancangan antarmuka dan dokumentasi kebutuhan sistem.

## Project Objectives

- Merancang aplikasi layanan jasa yang mudah digunakan.
- Menyediakan pengalaman pengguna yang sederhana dan intuitif.
- Menyusun alur penggunaan aplikasi berdasarkan kebutuhan pengguna.
- Mengembangkan desain antarmuka untuk berbagai jenis pengguna.

## User Roles

- **Customer:** Pengguna yang mengakses aplikasi untuk menggunakan layanan jasa.
- **Guest:** Pengunjung yang dapat mengakses aplikasi tanpa masuk sebagai pelanggan.
